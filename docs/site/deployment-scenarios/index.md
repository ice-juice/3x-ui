# Deployment Scenarios

Deployment Scenarios answer the operational question first: which topology should you choose, and which 3x-ui pages must be configured together?

Use this section before tuning individual fields. The guide pages under **Operate**, **Panel Settings**, and **Xray Configuration** explain each menu area; deployment scenarios connect those menu areas into a working path.

## Available Scenarios

| Scenario | Use it when | Main pages involved |
| --- | --- | --- |
| [Reality Inbound](./reality-inbound.md) | You want a public single-node VLESS deployment using RAW/TCP and REALITY. | Inbounds, Clients, System Status |

## How to Read Scenario Pages

1. Confirm the topology matches your server layout.
2. Apply the recommended baseline first.
3. Test one client before enabling advanced options.
4. Return to the menu reference pages when you need field-level details.
