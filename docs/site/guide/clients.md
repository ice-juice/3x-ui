# 客户端 / Clients

客户端页面用于集中管理订阅用户、流量额度、到期时间、分组和关联入站。

The Clients page manages subscription users, traffic quotas, expiry, groups, and inbound attachment.

| Section | Planned content |
| --- | --- |
| Create Client | UUID, email, traffic quota, expiry time, and enabled state. |
| Bulk Actions | Batch quota changes, traffic reset, and deletion strategy. |
| Subscription | Share links, QR codes, subscription URLs, and export formats. |
| Inbound Binding | Relationships between clients, inbounds, groups, and nodes. |
