# Groups

The Groups page organizes clients by business case, user group, or plan.

| Section | Planned content |
| --- | --- |
| Create Group | Name, purpose, ordering, and default strategy. |
| Membership | Add, remove, migrate, and batch assign clients. |
| Plan Structure | Organize users by business, region, pricing, or access. |
| Operations | Filtering, statistic boundaries, and cleanup routines. |
