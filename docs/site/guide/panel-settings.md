# 面板设置 / Panel Settings

面板设置页面用于管理 3x-ui 面板自身、安全、Telegram 机器人和订阅相关配置。

The Panel Settings page manages the 3x-ui panel itself, security settings, Telegram bot integration, and subscription behavior.

| Tab | Planned content |
| --- | --- |
| General | Panel port, base path, language, time, and display settings. |
| Security | Login security, TLS, certificates, URI paths, and security alerts. |
| Telegram Bot | Bot token, administrators, notifications, and commands. |
| Subscription | Subscription switch, path, domain, templates, traffic display, and expiry strategy. |
| Sub Formats | JSON, Clash, and other subscription output formats. |
