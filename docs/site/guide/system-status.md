# 系统状态 / System Status

系统状态页面用于查看面板与 Xray 运行状态、系统资源、流量与指标概览。

The System Status page summarizes panel health, Xray runtime state, resource usage, traffic, and metrics.

| Section | Planned content |
| --- | --- |
| Resources | CPU, memory, disk, network rate, and uptime. |
| Xray Runtime | Start, stop, restart, logs, and version state. |
| Traffic Metrics | Inbound traffic, client traffic, and chart definitions. |
| Updates & Alerts | Panel version, Xray version, and abnormal status prompts. |
