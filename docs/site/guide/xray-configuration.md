# Xray 配置 / Xray Configuration

Xray 配置页面用于编辑 Xray 基础模板、路由、出站、负载均衡、DNS 和高级 JSON。

The Xray Configuration page edits Xray basic templates, routing, outbounds, balancers, DNS, and advanced JSON.

| Tab | Planned content |
| --- | --- |
| Basic | Logs, API, policy, stats, metrics, and base templates. |
| Routing | Blocking, direct, proxy, domain/IP rules, and rule priority. |
| Outbounds | Outbound protocols, testing, traffic stats, WARP/Nord integration, and chained proxying. |
| Balancers | `balancerTag`, `selector`, strategies, and routing integration. |
| DNS | DNS servers, FakeDNS, preset templates, and query strategy. |
| Advanced | Full Xray JSON, inbound/outbound/routing fragment editing, and save-restart flow. |
