# 入站 / Inbounds

入站页面用于创建、管理、导入、导出和查看 Xray 入站配置。

The Inbounds page is used to create, manage, import, export, and inspect Xray inbound configurations.

## What belongs here

| Section | Purpose |
| --- | --- |
| Reality Inbound | Recommended VLESS + RAW/TCP + REALITY configuration and field impacts. |
| Protocol Settings | VLESS-specific authentication, encryption, and Vision options. |
| Transport Settings | RAW/TCP, proxy protocol, HTTP camouflage, sockopt, and FinalMask choices. |
| Sniffing | Server-side destination detection and routing behavior. |
