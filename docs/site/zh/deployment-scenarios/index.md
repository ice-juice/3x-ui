# 部署场景

部署场景先回答运维问题：应该选择哪种拓扑，以及哪些 3x-ui 页面需要一起配置。

在调单个字段之前，建议先阅读本章节。**运维**、**面板设置**、**Xray 配置**下的页面负责解释每个菜单区域；部署场景负责把这些菜单串成可落地的路径。

## 可用场景

| 场景 | 适用情况 | 主要涉及页面 |
| --- | --- | --- |
| [Reality 入站](./reality-inbound.md) | 使用 RAW/TCP 和 REALITY 创建公网单节点 VLESS 部署。 | 入站、客户端、系统状态 |

## 如何阅读场景页

1. 先确认拓扑是否符合你的服务器布局。
2. 先按推荐基线配置。
3. 只测试一个客户端，确认可用后再开启高级选项。
4. 需要字段细节时，再回到对应的菜单参考页面。
