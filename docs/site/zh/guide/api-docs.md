# API 文档

API 文档页面是基于面板内置 OpenAPI 描述的 Swagger UI。它适合查看请求和响应结构、核对认证方式，并基于当前服务端版本测试接口。

## 用途

- 浏览当前面板版本暴露的 API。
- 查看接口分组、参数、示例和常见错误结构。
- 在已认证浏览器会话中直接测试请求。
- 为脚本、机器人、集中面板和运维工具提供对接依据。

## 认证方式

| 方式 | 适用场景 |
| --- | --- |
| 会话 Cookie | 浏览器内面板操作和 Swagger UI 测试。 |
| `X-CSRF-Token` | 需要 CSRF 保护的浏览器会话写操作。 |
| `Authorization: Bearer <token>` | 程序化脚本、机器人和远程集成。 |

## 重要接口区域

| 区域 | 示例 |
| --- | --- |
| OpenAPI | `GET /panel/api/openapi.json` |
| 服务端 | 状态、日志、配置 JSON、Xray 版本和重启动作。 |
| Xray 设置 | 读取和更新保存的 Xray 模板。 |
| 入站 | 创建、更新、删除、导入、导出和重置入站数据。 |
| 客户端 | 管理订阅用户、额度、到期、分组和订阅。 |
| 节点 | 注册并探测远程面板节点。 |
| 设置 | 读取和更新面板、安全、Telegram 和订阅设置。 |
| API Token | 创建和管理 Bearer Token。 |
| WebSocket | 已认证的实时面板更新。 |

## 注意事项

- 页面外壳是 Swagger UI，真实规范来自 `/panel/api/openapi.json`。
- 请求体格式因接口而异，可能是 JSON、表单字段或路径参数。
- 破坏性接口包括重启 Xray、停止 Xray、重置流量、删除对象和导入数据库。
- WebSocket 更新依赖已认证会话，不应当作普通 Bearer-token REST 调用处理。

## 排障提示

| 现象 | 优先检查 |
| --- | --- |
| 页面打开但没有接口 | 检查 `/panel/api/openapi.json` 是否可访问。 |
| Try it out 返回 `401` | 浏览器会话缺失或过期。 |
| 浏览器请求出现 CSRF 错误 | 刷新或重新获取当前 `X-CSRF-Token`。 |
| 脚本调用失败 | 确认接口需要会话流程还是 Bearer Token 流程。 |
| Xray 重启成功但流量仍异常 | 查看 Xray 结果日志和实际组装的运行配置。 |
