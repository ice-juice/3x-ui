# 客户端

客户端页面管理订阅用户本身，而不是某一条入站。它适合处理额度、到期、分组、订阅分发和多入站绑定。

## 用途

- 管理客户端邮箱、启用状态、分组、注释、到期时间和流量额度。
- 查看客户端是否在线、离线、禁用、耗尽或即将耗尽。
- 将一个客户端绑定到多个入站，或批量解除绑定。
- 生成订阅链接、二维码和批量分发结果。

## 常用操作

- 新增或编辑单个客户端。
- 打开客户端信息弹窗或二维码弹窗。
- 重置单个客户端流量，或重置全部客户端流量。
- 批量调整流量和到期时间。
- 将客户端加入分组或从分组移除。
- 把选中客户端附加到入站，或从入站解除。
- 执行批量操作前，先确认搜索、筛选和排序条件。

## 主要列

| 列 | 含义 |
| --- | --- |
| 启用 | 客户端是否允许连接。 |
| 在线 | 在线、离线、禁用、耗尽或即将耗尽状态。 |
| 客户端 | 邮箱，以及可选的 `subId` 和备注。 |
| 分组 | 用于套餐、渠道或租户的运营分组。 |
| 入站 | 客户端绑定的一个或多个入站。 |
| 流量 | 已用上行、下行和总额度。 |
| 剩余 | 剩余额度或无限额度状态。 |
| 时长 / 到期 | 相对到期、延迟生效或无限期状态。 |

## 注意事项

- 列表是分页和服务端筛选结果，不等于原始全量导出。
- 编辑和详情操作会额外加载完整客户端记录，因为列表数据有意保持精简。
- 批量延期或加流量不会把无限期或无限流量自动改成有限值。
- 一个客户端绑定多个入站时，仍然共享同一个用户身份和流量模型。
- 搜索、筛选、排序和当前勾选范围都会影响批量操作。

## 排障提示

| 现象 | 优先检查 |
| --- | --- |
| 客户端显示离线但实际可用 | 对比在线判定窗口和最近在线时间。 |
| 订阅链接为空 | 确认客户端存在 `subId`，并且订阅输出已启用。 |
| 批量附加入站失败 | 检查目标入站是否已包含该客户端，或协议是否不兼容。 |
| 批量调整跳过部分客户端 | 检查这些客户端是否为无限期或无限流量。 |
| 找不到客户端 | 先清空筛选器，再检查分页、分组筛选和搜索词。 |
