# 节点

节点页面用于管理远程面板节点，并展示可达性、延迟、版本、资源状态和客户端统计。它是多节点部署的运维入口。

## 用途

- 添加、编辑、启用、禁用和删除远程节点。
- 查看最近心跳、延迟、CPU、内存、Xray 版本和面板版本。
- 按需发起节点连通性探测。
- 从控制面板更新符合条件的远程面板。
- 区分哪些入站属于本地节点，哪些属于远程节点。

## 常用操作

- 填写协议、地址、端口、基础路径、API Token 和 TLS 校验方式添加节点。
- 在承载流量前先测试连通性。
- 使用证书固定时，先获取并保存证书指纹。
- 运维时按需隐藏或显示节点地址。
- 更新单个符合条件的节点，或批量更新选中节点。

## 主要字段

| 字段 | 含义 |
| --- | --- |
| `scheme` | 远程面板 API 使用 `http` 或 `https`。 |
| `address` | 远程面板域名或 IP 地址。 |
| `port` | 远程面板端口。 |
| `basePath` | 远程面板基础路径。 |
| `apiToken` | 控制面板访问节点时使用的认证令牌。 |
| `allowPrivateAddress` | 在确实需要时允许私有或本地地址范围。 |
| `tlsVerifyMode` | TLS 校验行为，包括跳过或证书固定模式。 |
| `pinnedCertSha256` | 证书固定模式下期望的证书指纹。 |

## 注意事项

- 只有启用且在线的节点才属于可更新对象。
- 使用 `http` 等同于跳过 TLS 校验。
- 证书固定模式需要获取并保存正确证书指纹。
- 删除节点不会自动迁移绑定到该节点的入站。
- 平均延迟只统计启用、在线且返回有效延迟的节点。

## 排障提示

| 现象 | 优先检查 |
| --- | --- |
| 探测失败 | 检查协议、地址、端口、基础路径、API Token 和 TLS 模式。 |
| 节点离线 | 查看最近错误，并测试到远程面板 API 的网络连通性。 |
| 更新按钮不显示 | 节点可能未启用、离线或已经是最新版本。 |
| 证书固定失败 | 重新获取指纹，并确认没有代理替换证书。 |
| 删除节点后入站异常 | 检查这些入站是否仍引用旧节点 ID。 |
