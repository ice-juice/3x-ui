# 常规

面板设置中的常规页面控制 3x-ui 面板自身如何暴露，以及面板级默认行为如何生效。

## 用途

- 配置面板监听地址、域名、端口和基础路径。
- 设置会话有效期、受信任反向代理、语言、时区和分页大小。
- 配置面板 HTTPS 证书路径。
- 控制外部流量回调，以及客户端变化后是否重启 Xray。

## 关键设置

| 设置 | 作用 |
| --- | --- |
| `webListen` | 面板绑定地址。留空或绑定全部地址会在所有网卡上监听。 |
| `webDomain` | 面板生成访问 URL 时使用的外部域名。 |
| `webPort` | 面板监听端口。常见默认值为 `2053`。 |
| `webBasePath` | 面板 URL 基础路径。不要长期保持默认 `/`。 |
| `sessionMaxAge` | 管理员会话有效期。 |
| `trustedProxyCIDRs` | 受信任、可转发真实客户端信息的反向代理网段。 |
| `panelProxy` | 面板访问外部资源时使用的出站代理。 |
| `pageSize` | 列表视图默认行数。 |
| `webCertFile` / `webKeyFile` | 面板 HTTPS 证书和私钥路径。 |
| `timeLocation` | 面板显示和计划任务使用的时区。 |

## 推荐做法

- 公网暴露前，把 `webBasePath` 从默认 `/` 改成不易猜测的路径。
- 如果面板位于 Nginx、Caddy 或 CDN 后面，`trustedProxyCIDRs` 只填写真实代理链。
- 启用 HTTPS 时，同时填写证书和私钥路径，并确认文件存在。
- `pageSize` 保持适中，避免大列表加载过慢。
- 只有面板确实需要可控出站代理时，再配置 `panelProxy`。

## 风险与注意事项

- 使用 HTTP、默认端口 `2053` 或默认路径 `/` 会增加被扫描命中的概率。
- 修改域名、端口、基础路径或证书设置后，旧访问地址可能在重启后立即失效。
- `trustedProxyCIDRs` 配置过宽会削弱来源 IP 信任边界，并影响审计和链接生成。
- 路径字段会被界面规范化，但最终 URL 仍应手动确认。
