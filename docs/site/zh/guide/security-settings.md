# 安全设定

安全设定用于管理管理员凭证、两步验证，以及脚本、机器人、远程面板和自动化系统使用的 API Token。

## 用途

- 修改管理员用户名和密码。
- 启用或关闭两步验证。
- 创建、启用、禁用和删除 API Token。
- 区分人工登录安全和程序化访问安全。

## 关键设置

| 设置 | 作用 |
| --- | --- |
| 当前用户名 / 密码 | 修改凭证前确认现有管理员身份。 |
| 新用户名 / 密码 | 替换管理员凭证。 |
| `twoFactorEnable` | 管理员登录和敏感更新时要求第二因素。 |
| API Token 名称 | 标识每个集成或自动化用途。 |
| API Token 状态 | 允许临时禁用，而不是直接删除。 |

## 推荐做法

- 替换默认凭证，并避免使用容易猜测的管理员名称。
- 公网可访问的面板建议启用两步验证。
- 为每个集成单独创建 Token，便于精准吊销。
- 使用清晰名称，例如 `backup-bot`、`central-panel`、`node-sync`。
- 排障时优先禁用 Token，确认不再使用后再删除。

## 风险与注意事项

- 管理员凭证修改成功后，界面会登出并跳回登录入口。
- 开启两步验证后，修改管理员凭证也需要额外确认。
- 新建 API Token 的明文只显示一次，应立即保存。
- 禁用或删除 Token 会让依赖它的所有调用方立刻失效。
