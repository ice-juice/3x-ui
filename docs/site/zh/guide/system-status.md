# 系统状态

系统状态页面是检查主机健康、Xray 运行状态、实时速率、连接数、日志、备份和版本操作的第一入口。

## 用途

- 通过 CPU、内存、Swap 和磁盘占用判断面板主机是否健康。
- 查看 Xray 是否处于运行、停止或报错状态。
- 查看实时速率、累计流量、运行时长、公网 IP 和连接数。
- 打开日志、备份、系统历史和 Xray 指标，继续深入排查。

## 常用操作

- 在修改运行时配置前，先查看 CPU、内存、Swap 和磁盘仪表盘。
- 配置变更后，通过 Xray 状态卡片重启 Xray。
- 打开 **Config** 查看只读运行态 `config.json`。
- Xray 报错或重启失败时，打开 **Logs**。
- 使用 **System History** 和 **Xray Metrics** 看趋势，而不是只看单次快照。
- 升级前查看 3x-ui 版本卡片，方便与其他服务器行为做对比。

## 主要区域

| 区域 | 显示内容 |
| --- | --- |
| 资源仪表盘 | CPU 使用率、逻辑核心、内存、Swap、磁盘和负载。 |
| Xray 状态 | 运行状态、版本、错误摘要、重启控制和日志入口。 |
| 运行时长 | 操作系统和 Xray 的独立运行时长。 |
| Usage | 面板进程内存和线程数。 |
| Overall Speed | 当前上传和下载速率。 |
| Total Data | 累计发送和接收流量。 |
| IP Addresses | 公网 IPv4 和 IPv6，并支持隐藏显示。 |
| Connection Count | 当前 TCP 和 UDP 连接数。 |

## 注意事项

- **Config** 是只读查看弹窗，不是编辑器。
- 面板版本更新和 Xray 版本切换是两类独立操作。
- 分享截图或录屏前，建议隐藏 IP 地址。
- 指标适合看趋势，但不能替代入站级或客户端级明细分析。

## 排障提示

| 现象 | 优先检查 |
| --- | --- |
| Xray 显示错误 | 先看错误摘要，再打开 Xray 日志。 |
| 面板卡顿 | 检查 CPU、内存、Swap、线程数和磁盘压力。 |
| 带宽突增 | 对比实时速率和系统历史，再回到入站与客户端缩小范围。 |
| 公网 IP 缺失或异常 | 检查服务器网络、反向代理路径和部署拓扑。 |
| 重启后仍未恢复 | 检查 `config.json`、Xray 日志和当前 Xray 版本。 |
