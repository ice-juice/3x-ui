# 高级配置

高级配置提供完整 Xray 模板以及 `inbounds`、`outbounds`、`routing.rules` 等片段的直接 JSON 编辑入口。

## 用途

- 查看最终保存的模板。
- 编辑没有专门表单控件的字段。
- 修复或比对 `inbounds`、`outbounds` 和 `routing.rules` 片段。
- 保存模板，并在结构性变更后重启 Xray。

## 编辑模式

| 模式 | 用途 |
| --- | --- |
| 完整模板 | 查看或替换完整 Xray 配置模板。 |
| 入站 | 检查生成的入站对象和面板管理的兼容字段。 |
| 出站 | 表单未暴露字段时，直接编辑出站数组。 |
| 路由 | 直接编辑有序路由规则。 |

## 推荐做法

- 大幅编辑前，先复制当前 JSON。
- 一次只做一个概念变更并保存。
- 结构性变更后重启 Xray。
- 原始编辑后回到表单页确认仍能正常渲染。
- 除非明确知道影响，不要破坏面板管理的内部路由、API 和统计对象。

## 风险与注意事项

- JSON 语法校验只能发现格式错误，不能发现所有 Xray 语义错误。
- 这里编辑的是模板，不是运行时热补丁。
- 表单页和原始 JSON 页编辑的是同一个模板，避免混用时产生误判。
- 后端校验可能规范化或修复内部统计路由。

## 排障提示

| 现象 | 优先检查 |
| --- | --- |
| 保存被阻止 | 修复 JSON 语法、括号、尾逗号或根结构。 |
| 保存成功但 Xray 启动失败 | 查看 Xray 结果日志中的语义配置错误。 |
| 其他页签渲染异常 | 检查对象层级、数组结构和字段类型。 |
| 统计在原始编辑后失效 | 确认内部 API 和 stats 路由仍存在。 |
