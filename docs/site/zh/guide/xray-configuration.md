# Xray 配置

Xray 配置页面用于编辑 Xray 基础模板、路由、出站、负载均衡、DNS 和高级 JSON。

| 页签 | 待补充内容 |
| --- | --- |
| 基础配置 | 日志、API、策略、统计、指标和基础模板。 |
| 路由规则 | 阻断、直连、代理、域名/IP 规则和优先级。 |
| 出站 | 出站协议、测试、流量统计、WARP/Nord 集成和链式代理。 |
| 负载均衡 | `balancerTag`、`selector`、策略和路由联动。 |
| DNS | DNS 服务器、FakeDNS、预设模板和查询策略。 |
| 高级配置 | 完整 Xray JSON、入站/出站/路由片段编辑和保存重启流程。 |
