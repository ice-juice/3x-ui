# 出站

出站定义 Xray 在路由选中出口后如何发送流量。列表中的第一个出站通常也是没有命中路由时的默认路径。

## 用途

- 管理代理、直连、阻断、DNS 和链式出站。
- 测试单个出站或全部出站。
- 重置出站流量计数。
- 导入支持的出站分享链接。
- 使用 WARP 或 NordVPN 辅助生成出站模板。

## 关键字段

| 字段 | 作用 |
| --- | --- |
| `tag` | 被路由、负载均衡和链式代理引用的唯一名称。 |
| `protocol` | 出站协议，例如 freedom、blackhole、socks、VLESS、VMess、Trojan 或 WireGuard。 |
| `sendThrough` | 出站流量使用的本地源地址。 |
| `settings` | 协议特定设置。 |
| `streamSettings` | 传输、TLS、REALITY、sockopt 和 FinalMask 设置。 |
| `mux` | 支持时使用的多路复用设置。 |
| `proxySettings` | 链式出站依赖。 |
| `settings.flow` | 兼容协议使用的 flow 值。 |

## 推荐做法

- 每个 `tag` 保持唯一且有意义。
- 将预期默认出站放在第一位。
- 重命名或删除出站前，检查路由规则、负载均衡器和链式出站。
- 测试复杂代理链时，带上 `allOutbounds` 上下文以解析依赖。
- 把 WARP 和 NordVPN 辅助功能视为会修改模板的生成器。

## 排障提示

| 现象 | 优先检查 |
| --- | --- |
| 单个出站测试失败 | 检查地址、端口、凭证、SNI、指纹、传输和安全设置。 |
| 链式出站失败 | 确认每个依赖出站仍存在且 tag 未变化。 |
| 界面保存正常但流量失败 | 重启 Xray，并查看最新 Xray 结果日志。 |
| UDP 类出站测试表现奇怪 | 部分出站类型会通过更保守的 HTTP 探测方式测试。 |
