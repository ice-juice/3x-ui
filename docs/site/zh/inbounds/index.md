# 入站

入站页面用于创建、启停、导入、导出、克隆和查看 Xray 入站配置。它是查看协议、端口、流量、客户端、节点归属和到期状态的运维列表。

## 用途

- 管理本地或远程节点上的入站配置。
- 查看每个入站的协议、端口、节点归属、客户端数量、流量和到期状态。
- 导出分享链接、订阅链接或原始入站 JSON。
- 对多用户入站执行客户端附加、解除、迁移、分组和清空。

## 常用操作

- 使用 **添加入站** 新建入站。
- 导入入站 JSON 或支持的分享链接。
- 导出全部链接或全部订阅。
- 重置单个入站或全部入站流量。
- 编辑、克隆、删除、查看详情或导出单条入站。
- 对多用户入站附加已有客户端、把客户端附加到其他入站、解除客户端或把选中客户端加入分组。

## 主要列

| 列 | 含义 |
| --- | --- |
| 启用 | 入站是否接受连接。关闭后配置保留，但不再提供服务。 |
| 备注 | 用于运维识别和导出名称的人类可读标签。 |
| 节点 | 入站所属的本地或远程节点。 |
| 端口 | 入站监听端口。 |
| 协议 | 协议以及传输、TLS、Reality、网络等标签。 |
| 客户端 | 客户端总数，以及活跃、禁用、耗尽、在线计数。 |
| 流量 | 已用流量、总额度、剩余额度、上行和下行。 |
| 到期 | 相对到期时间或无限期状态。 |

## 注意事项

- 多用户入站和单用户入站的操作菜单不同。
- 克隆入站会生成一个默认禁用、随机端口、空客户端列表的副本。
- 清空入站客户端属于破坏性操作，执行前应确认迁移或下线已经完成。
- 导出链接会受到订阅设置、公网地址覆盖和节点地址覆盖影响。
- 包括 Reality 在内的部署方案已经移动到 [部署场景](/zh/deployment-scenarios/)。

## 排障提示

| 现象 | 优先检查 |
| --- | --- |
| 链接或二维码主机不对 | 检查节点地址覆盖、订阅公网地址和外部代理设置。 |
| 客户端无法连接 | 核对端口、协议、flow、安全层、传输层、SNI 和客户端 UUID。 |
| 远程节点入站异常 | 先检查节点页面，再确认入站仍绑定到正确节点。 |
| 流量颜色异常 | 检查入站额度和全局流量告警阈值。 |
| 导入失败 | 检查粘贴内容是否合法，再查看日志中的解析错误。 |
