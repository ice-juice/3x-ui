## 编写风格 / Writing System

| 原则 / Principle | 说明 / Description |
| --- | --- |
| 菜单优先 / Menu first | 页面顺序与 3x-ui 前端侧边栏保持一致。 |
| 配置可复现 / Reproducible | 每个关键字段说明推荐值、影响和风险。 |
| 中英双语 / Bilingual | 中文为主，英文用于标题别名和摘要。 |
| 少装饰 / Clean UI | 使用表格、状态标签和短段落形成清晰的信息层次。 |
